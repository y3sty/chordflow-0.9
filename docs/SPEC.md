# Chordflow · Спецификация дизайна v0.9

Статус: черновик к утверждению · 25.09.2026
Охват: компонентная система + две темы («scene» = концепт A, «paper» = концепт B)
Макеты-источники: `redesign/concept-a/index.html`, `redesign/concept-b/index.html`
Миграция: разметка и классы заменяются, `id` элементов из текущего `index.html` сохраняются для `app.js`/`ui.js`.

---

## 1. Принципы

1. **Ритм — это интерфейс.** Бой (последовательность вниз/вверх) всегда крупнее и контрастнее любого другого элемента карточки. Если элемент спорит со стрелками боя за внимание — он лишний.
2. **Один экран = одна песня.** Структура (части, порядок, такты) видна целиком без переключений табов.
3. **Инструмент, а не витрина.** Все действия в один клик/тап от текущей позиции; вторичное (облако, файлы, настройки) — в поповерах.
4. **Тема ≠ система.** Геометрия, сетка, компоненты и состояния одинаковы для A и B; отличаются только токены цвета, шрифтовая пара и характер границ/теней.

## 2. Информационная архитектура

```
topbar      : бренд · имя песни · [Сохранить+код] · [Текст песни] · [RU/CS]
playbar     : Play · Stop | сегмент боёв | темп | цикл | фон+длительность | readout(доли+позиция)   [sticky]
arrange     : порядок песни чипами (цвет части + ×повторы) + «+ часть»
main        : palette (аккорды: поиск, тайлы, доп. аккорды)  |  map (дорожки частей с блоками-тактами)
overlays    : lyrics (текст+автоскролл), popover сохранения (файл/облако/настройки/глушение)
```

Убрано из постоянной видимости: строка «Код песни», строка «Дополнительные настройки» (−150px высоты), дубли аппликатур в таймлайне, постоянно видимые кнопки действий в карточке такта.

## 4. Пространство, радиусы, тени

- Шкала отступов: 4 / 8 / 12 / 16 / 22 / 28 / 40. Внутренние паддинги карточек: блок такта 11–12px, лейн 14–18px, панель 16–18px.
- Радиусы: `--r-sm` 8 · `--r` 10–12 (контролы, карточки) · `--r-lg` 14–16 (панели, лейны) · `--r-pill` 999.
- Тени: A — мягкие `0 10px 30px rgba(0,0,0,.45)` + ring-свечение акцента; B — жёсткие offset `4px 4px 0 --ink` (карточки), `3px 3px 0 --ink` (активный блок). Тень = маркер темы, не компонента.

## 7. Компоненты (геометрия общая)

**Play** — круг 52px (A) / 66px (B); заливка `--accent` (A) / `--ink` с лаймовым глифом (B); ring `0 0 0 6px accent-soft`; при воспроизведении глиф = пауза, ring пульсирует 1.6s.
**Stop** — круг 38/44px, border `--line-strong`, глиф `--text-muted`.
**Сегмент боёв** — контейнер radius 12, padding 3–4, border `--line`; опция: имя 11.5/700 + паттерн моно 9.5; активная: заливка `accent-soft`, текст `--accent`, inset-ring 1px accent 35% (A); в B активная подчёркнута 3px `--section-2`.
**Темп** — label eyebrow + значение моно 26 (A) / Unbounded 46 (B) + «BPM» faint + range 130–150px, accent-color = `--accent` (A) / `--ink` (B) + степпер −/+ для тача (моб.).
**Toggle pill / checkbox chip** — высота 32–34px, radius 999; свитч 26×15 (A) / чекбокс 14×14 с лаймом (B); включено: текст `--accent` (A) / заливка лайм (B).
**Readout** — 4 точки долей 7px (активная `--accent` + glow) + позиция моно 12; в B — инверсная плашка ink/lime radius 8.
**Arrange chip** — h 28–30, radius 8–9, border `--line`; метка части 7–9px radius 2–3; `×N` моно 10 faint; «+ часть» — dashed.
**Lane (дорожка части)** — панель radius 14–16; шапка: метка 9–13px + имя 13–16/800 + `×N` моно; действия (дублировать/стереть) 26–28px, видны по ховеру (на таче — всегда).
**Block (такт)** — w 138–142, radius 12–13, padding 11–13; индекс моно 9.5 справа сверху; имя аккорда 20–22/800; стрелки боя 11–12×18–20, gap 5–6: вниз = `--accent`/ink сплошь, вверх = 42–80% прозрачности, глушение = крест `--text-faint`; степпер тактов: border `--line`, radius 7–8, значение моно 11.
  Состояния: hover — border `--line-strong`, translateY(−1px); drag-over — dashed `--accent`; **now** (играет) — border `--accent` + ring 3px accent-soft (A) / заливка `--accent` + offset-тень (B), стрелки загораются по порядку удара.
**Add-block** — 52–54px, dashed `--line-strong`, «+» faint; hover — `--accent`.
**Palette tile** — radius 11–12, padding 8–9; имя 12.5–13.5/800 + тип капс 8–8.5 faint; аппликатура SVG 54–58×42–44: струны `--line-strong`, ладовые точки `--accent` (A) / `--ink` (B), «×/○» faint/muted; hover — border accent 50% (A) / заливка лайм (B).
**Search** — h 34, radius 10, surface-2, иконка 13, placeholder faint.
**Tool button** — h 32–34, radius 9–10, border `--line`, 11.5/600 muted; danger: hover текст `--danger` + border danger 40%.
**Popover сохранения** — width 320, radius 14, surface-1, border `--line`, тень по теме; секции: файл (сохранить/открыть), облако (код+2 кнопки+статус), настройки (глушение, структура), язык.
**Lyrics overlay** — как сейчас: модалка, textarea 18px, автоскролл, скорость 1–5; стиль по теме, акцент на кнопке сохранения.
**Empty state** — пунктирная рамка лейна + текст muted 12 + кнопка-подсказка «добавить из библиотеки».
**Toast/статус** — моно 11, внизу плейбара или в поповере; ok = `--accent`, error = `--danger`.

## 8. Состояния и движение

- Переходы: 120–160ms ease-out на hover/border/заливки; 200ms на поповеры/оверлеи (fade+4px slide).
- Воспроизведение: ring на активном блоке + подсветка стрелок по порядку удара (шаг = доля паттерна); точки долей в readout; playhead-полоса 2px `--accent` под активной дорожкой.
- Drag&drop: призрак тайла 80% opacity, зона вставки dashed `--accent`.
- Загрузка фона (WAV): спиннер-нота в кнопке + прогресс-полоса 2px в плейбаре.
- `prefers-reduced-motion`: отключать пульсации/подсветку стрелок, оставлять статичный ring.

## 9. Доступность

- Focus-visible: ring 2px `--focus`, offset 2px, на всех интерактивных.
- Тач-таргеты ≥ 36px (моб. степперы и стрелки лейнов — ≥ 40px).
- `aria-live=polite` для статуса аудио/облака (сохранён из текущей версии), `aria-modal` у lyrics.
- Клавиатура: Tab-порядок topbar → playbar → arrange → palette → map; Space = play/stop вне input; стрелки ±1 BPM на сфокусированном темпе.
- Цвета частей дублируются формой/подписью (не только цветом): метка + имя части текстом.
