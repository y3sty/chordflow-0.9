# Chordflow · чек-лист ручного теста перед релизом

Версия сборки: 25.09.2026 · single-file `chordflow-redesign.html` + multi-file `prototype/`
Авто-покрытие: 23/23 e2e (`TEST-REPORT.md`). Этот лист — для ваших рук и глаз.

## Где тестировать

| Контур | Как | Что доступно |
|---|---|---|
| A. Предпросмотр в просмотрщике | открыть `chordflow-redesign.html` в workspace | всё, кроме облака и скачивания файла (нет сети/allow-downloads) |
| B. Локально, двойной клик | скачать `chordflow-redesign.html`, открыть в браузере | всё, включая облако и скачивание |
| C. localhost + телефон | распаковать `chordflow-prototype.zip`, запустить `start-localhost.command/.sh/.bat` | всё + тест с телефона по Wi-Fi (адрес напечатает скрипт) |

Сброс состояния: очистить данные сайта / удалить ключи `guitar-constructor-session-v1`, `guitar-constructor-lyrics-v1`, `chordflow-theme-v2`.
